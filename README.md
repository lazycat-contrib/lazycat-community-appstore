# 喵喵商店

喵喵商店提供懒猫 LPK 软件源浏览、安装与管理功能，包含独立的客户端和服务端。

## 客户端

用于浏览应用与软件源、查看版本和更新说明，并在懒猫微服中安装应用。适合直接连接已有商店或软件源使用，无需同时部署服务端。

- 支持添加和切换软件源。
- 查看应用详情、截图、版本和更新说明。
- 安装 LPK 应用，集中浏览可用的软件包。

## 服务端

用于自托管 LPK 商店，提供 Web 管理控制台和软件源接口。适合维护自己的应用目录、管理安装包版本，或向家庭和团队分发应用。

- 管理应用信息、版本、截图和下载内容。
- 管理用户、权限与私有分组。
- 对外提供供客户端浏览、下载和安装的软件源。

## 安装与下载

| 组件 | 包 ID | 系统要求 | 安装渠道 |
|---|---|---|---|
| 客户端 | `community.lazycat.app-store` | 懒猫系统 1.6.0+ | 喵喵商店、官方商店 |
| 服务端 | `community.lazycat.app-store-server` | 懒猫系统 1.5.2+ | 喵喵商店 |

也可在本仓库 Releases 下载 LPK 手动安装。`client-v` 开头的发布对应客户端，`server-v` 开头的发布对应服务端；各自的 `checksums.txt` 提供 SHA256 校验信息。

客户端与服务端分别安装、独立更新，可按需要选择其中一个或同时使用。

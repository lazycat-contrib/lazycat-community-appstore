# 双端界面质感优化与发布

## 范围与验收

- 保留 Astryx 主题、现有导航和业务逻辑，不引入动画依赖或远程字体。
- 双端统一卡片圆角、表面层级、页面留白、搜索焦点与结果栏；非交互面板不产生悬浮反馈。
- 客户端筛选无结果提供清除筛选，保留真正空软件源时的添加入口。
- 偶发弹窗用 200ms opacity/transform 表示出现；键盘触发即时显示，reduced-motion 只淡入。
- 桌面与 375px 移动端检查双端页面、弹窗、暗色主题和无横向溢出。

## 执行顺序

1. 统一结果摘要组件并修复客户端空结果恢复路径。
2. 调整现有共享样式，避免额外叠加一层设计系统。
3. 添加回归契约测试，运行前端测试、构建、Go 测试及浏览器检查。
4. 递增客户端与服务端 package 版本，提交并分别推送发布 tag。
5. 读回 CI、公开 Release、LPK 资产及商店发布结果；不把 tag 推送等同发布成功。

## 本地验证

- `npm test`：114 项通过；`npm audit --audit-level=high --registry=https://registry.npmjs.org`：0 vulnerabilities。
- `npm run build` 和 `go test ./...` 通过；前端构建结果与嵌入资源一致（排除运行时配置）。
- 隔离 SQLite 实例验证服务端后台及客户端软件源同步；筛选空结果清除后恢复应用列表。
- 375px 客户端与服务端设置页无横向溢出；桌面/移动端暗色主题检查完成。
- 安装弹窗内层无重复动画，Escape 关闭后焦点返回触发按钮；键盘打开无 transition，reduced-motion 仅 120ms opacity。
- 真实懒猫设备的安装流程不在本地浏览器验证范围内。

## Apple Design 增量打磨

- 首轮客户端 0.1.52、服务端 0.1.64 已发布，不改写既有 tag。
- 商店目录移除外层面板，以留白而非嵌套边框分组；后台管理面板保持原有结构。
- 64px 应用图标、双行应用名、按字号区分的字距，以及右对齐胶囊安装操作。
- 版本、分类、更新时间仍可见，去掉重复徽章装饰；导航单层轻材质，减少透明度/增强对比度时回退实底。
- 不引入额外手势或装饰动画，保留首轮键盘与 reduced-motion 行为。
